# aurral-yandex-music-plugin

Плагин [Aurral](https://github.com/lklynet/aurral) для импорта плейлистов и «Мне нравится» из
[Яндекс Музыки](https://music.yandex.ru). Работает так же, как встроенный импорт Spotify: вы
вставляете ссылку на плейлист, Aurral получает список треков и дальше ищет и скачивает их своими
источниками.

Плагин отдаёт только метаданные (исполнитель, название, альбом, длительность, обложка). Он не
скачивает музыку и не обходит ограничения Яндекс Музыки.

## Возможности

- Импорт обычного плейлиста по ссылке `music.yandex.ru/users/<login>/playlists/<kind>`.
- Импорт плейлиста по новой ссылке `music.yandex.ru/playlists/<uuid>` (включая `lk.`/`ps.`).
- Импорт ссылок из iframe-плеера `music.yandex.ru/iframe/playlist/<login>/<kind>`.
- Импорт «Мне нравится» (kind `3`) с читаемым названием `Мне нравится — <владелец>`.
- Домены `music.yandex.ru`, `.com`, `.kz`, `.by`.
- Пропуск недоступных в регионе треков и подкастов; недоступные можно включить настройкой.
- Проверка токена кнопкой «Проверить» в настройках плагина.
- Автоматическая сборка и релиз через GitHub Actions, установка по ссылке на репозиторий.

## Установка в Aurral

1. Скачайте и запустите свой экземпляр Aurral.
2. Откройте **Settings → Plugins → Install from link**.
3. Вставьте ссылку на этот репозиторий:

   ```text
   https://github.com/ckpei7ka/aurral-yandex-music-plugin
   ```

   Aurral возьмёт `releases/latest` и скачает `.zip` из релиза. Поэтому сначала должен быть
   опубликован хотя бы один релиз (workflow делает это по тегу `v*`).
4. Откройте настройки плагина **Яндекс Музыка** и вставьте OAuth-токен Яндекса.
5. Нажмите **Проверить** — плагин покажет логин аккаунта.

### Где взять токен

Плагин использует неофициальный API Яндекс Музыки, которому нужен OAuth-токен. Откройте ссылку:

```text
https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
```

После подтверждения Яндекс перенаправит на `https://music.yandex.ru/#access_token=...`. Скопируйте
значение `access_token` из адресной строки. Плагин также принимает вставленный целиком URL — токен
из него извлекается автоматически. Токен действует около года; когда истечёт, повторите процедуру.

Токен хранится в настройках плагина внутри вашего экземпляра Aurral, никуда не отправляется, кроме
`api.music.yandex.net`, и не попадает в логи. Не публикуйте его.

## Импорт плейлиста

1. **Playlists → Import playlist**.
2. В качестве источника выберите **Яндекс Музыка**.
3. Вставьте ссылку на плейлист и нажмите **Preview**, затем **Import**.

После импорта плейлист ведёт себя как любой другой импортированный плейлист Aurral: его можно
синхронизировать по расписанию, а скачивание выполняют настроенные в Aurral источники. Повторная
синхронизация перезаписывает список треков актуальным из Яндекс Музыки.

## Настройки

| Ключ                 | Тип      | По умолчанию | Описание                                                                 |
| -------------------- | -------- | ------------ | ------------------------------------------------------------------------ |
| `token`              | password | —            | OAuth-токен Яндекс Музыки. Обязателен.                                    |
| `includeUnavailable` | boolean  | `false`      | Импортировать треки с `available: false` (недоступные в вашем регионе).   |

## Ограничения

- Плагин работает только на чтение: создавать плейлисты, ставить лайки и скачивать напрямую из
  Яндекс Музыки он не умеет.
- Стримы Яндекс Музыки зашифрованы, поэтому `downloadSource` не реализован: Aurral скачивает треки
  своими источниками по метаданным.
- Импортируется не больше 5000 треков за раз (ограничение Aurral).
- Подкасты и треки без исполнителя/названия пропускаются.
- Приватные плейлисты доступны, только если токен принадлежит аккаунту с доступом к ним.
- API Яндекс Музыки неофициальный и может меняться без предупреждения.

## Разработка

Требуется Node.js 20+.

```bash
npm ci
npm run check   # typecheck + тесты с покрытием + сборка + упаковка + проверка архива
```

Отдельные команды:

```bash
npm run build          # dist/yandex-music/{index.js,manifest.json}
npm run pack           # artifacts/aurral-yandex-music-plugin.zip
npm run test           # сборка + unit-тесты
npm run test:coverage  # сборка + тесты с покрытием (порог 85% строк, 80% ветвей)
npm run verify         # сборка + упаковка + проверка zip как его видит Aurral
```

Тесты не ходят в сеть: HTTP-клиент принимает `fetch` через внедрение зависимостей, а тест собранного
бандла подменяет глобальный `fetch`. Покрыты разбор ссылок и токена, HTTP-клиент и его ошибки,
маппинг ответов API, поведение плагина, правила манифеста и готовый zip-архив.

### Структура

```text
src/
  index.ts      точка входа, default export плагина
  plugin.ts     test и importList.fetch
  client.ts     HTTP-клиент api.music.yandex.net
  map.ts        ответ Яндекс Музыки → формат импорта Aurral
  url.ts        разбор и валидация ссылок
  token.ts      нормализация токена
  types.ts      типы API Яндекс Музыки
  aurral.ts     типы Plugin API 1
scripts/
  build.mjs             сборка бандла (TypeScript + Rollup, без нативных зависимостей)
  manifest-rules.mjs    копия правил манифеста Aurral
  pack.mjs              упаковка релизного zip
  verify-package.mjs    проверка zip и манифеста
  check-version.mjs     сверка тега и версии
test/                   unit- и интеграционные тесты
```

### Релиз

1. Обновите версию в `package.json` и `manifest.json` (они должны совпадать).
2. Закоммитьте изменения и поставьте тег:

   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```

3. Workflow **Release** прогонит все проверки, сверит тег с версией и опубликует
   `aurral-yandex-music-plugin.zip` в GitHub Releases.

Aurral при установке по ссылке на репозиторий использует последний релиз и первый `.zip`-ассет.
